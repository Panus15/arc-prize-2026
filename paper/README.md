## กติกาของไฟล์นี้

1. **เขียนเป็นภาษาอังกฤษ** — กรรมการอ่านอังกฤษ (เอกสารใน `docs/` เป็นไทยไว้ให้เจ้าของอ่าน)
2. **ห้ามใส่ตัวเลขที่ไม่ได้มาจาก `docs/`** — ทุกตัวเลขต้องย้อนกลับไปหาไฟล์ที่วัดไว้ได้
3. **ห้ามเคลมเรื่องคะแนน** จนกว่าจะรันเกมสดจริง — ดู `docs/paper-outline.md` §4 หัวข้อ unsupported

- §1 ย่อหน้าปิด — ควรจบด้วยสิ่งที่วัดได้กับเกมจริง
- §2 สถาปัตยกรรมที่รันบน Kaggle จริง
- §6 ลิงก์ repo + คำสั่ง reproduce
- §7 **ช่องว่างชั้นที่ 5 เจอหรือไม่** ← ส่วนที่ทำให้เปเปอร์แข็งที่สุด
