## 1. ผลจริงของผู้ชนะ — ต่ำกว่าที่คนส่วนใหญ่คิดมาก

รันเต็ม: **25 เกม × 20 trial** · คะแนนรวม **1.6002** (`taaf.final_score`)

| ตัวชี้วัด | ค่า |
|---|---|
| completion rate เฉลี่ย | **8.30%** |
| completion rate มัธยฐาน | **7.86%** |
| สูงสุด (เกม ft09) | 25.00% |
| **เกมที่ทำไม่ได้เลย 0%** | **2 จาก 25** |
| levels_completed ต่อ trial (มัธยฐาน) | **0.65** |
| level ทั้งหมดในชุด | 183 level จาก 25 เกม |

**อ่านให้ชัด: ผู้ชนะจบไม่ถึง 1 level ต่อ 1 trial โดยเฉลี่ย** และแพ้ราบคาบ 2 เกม
เกมหนึ่งมี 6–10 level แต่ระดับลึกสุดที่ไปถึงคือ:

| level ลึกสุดที่ไปถึง | จำนวนเกม |
|---|---|
| 1 | 12 |
| 2 | 10 |
| 3 | 2 |
| 4 | 1 |

→ **ไม่มีเกมไหนที่ไปได้เกิน level 4** จากที่มี 6–10 level

## 4. สถาปัตยกรรม

- **tool-using solver** — LLM เขียนโค้ด Python ในแซนด์บ็อกซ์เพื่อโต้ตอบกับเกม
  (`inference/agent/python_tool_sandbox.py`)
- **รันโมเดลในเครื่องผ่าน vLLM + LoRA** (`tools/vllm_runtime_lora_guard.py`)
  → **ไม่ใช่การเรียก API ภายนอก** สอดคล้องกับกติกาที่ปิด internet ตอน scoring
- ต้องใช้ **GPU** สำหรับรันจริง (แต่ดู viewer และ trace ได้โดยไม่ต้องมี GPU)
- Python 3.12 + `uv`
- มี TAAF (`tufa-arc-agi-framework`) เป็นชั้น `Benchmark` / `GameAPI`

## 5. ผลต่อการออกแบบของเรา

1. **เพดานต่ำจริง** — จบได้ 1 level ต่อ trial อย่างสม่ำเสมอก็แข่งขันได้แล้ว ไม่ต้องเล่นจบเกม
2. **ไม่ต้องคิดใหม่ทุกการกด** — อัตราส่วน 3.16 action/analysis คือจุดตั้งต้นที่มีหลักฐานรองรับ
   แทนที่จะเดาเอา (และสอดคล้องกับที่กติกาบอกว่า reasoning ฟรี แต่ action ถูกนับ)
3. **ทุ่มกับการเคลื่อนที่ก่อน** — 61% ของ action เป็น 4 ทิศ ส่วน MOUSE ซับซ้อนกว่าแต่ใช้น้อย
   → policy รุ่นแรกที่จัดการแค่ทิศทาง + SPACE ครอบคลุมพฤติกรรมส่วนใหญ่แล้ว
4. **ต้องใช้ GPU ถ้าจะเดินทาง LLM** — เป็นข้อจำกัดทรัพยากรที่ต้องตัดสินใจแต่เนิ่น ๆ
   ถ้าไม่มี GPU ต้องพิจารณาแนวทาง non-neural หรือโมเดลเล็กมาก
5. **RESET ใช้แค่ 1.2%** — ไม่ใช่ทางออก การรีเซ็ตทิ้งความคืบหน้าและเปลือง action

## 6. ยังไม่ได้ทำ

- ยังไม่ได้อ่าน prompt ที่ผู้ชนะใช้ (`inference/agent/prompts.py`)
- ยังไม่ได้ดูว่า analysis step ตัดสินใจอย่างไร (มี trace เต็มให้อ่าน)
- ยังไม่ได้เทียบว่าเกมที่ได้ 0% ต่างจากเกมที่ได้ 25% ตรงไหน
