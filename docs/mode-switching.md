# เกมบอกไม่หมดว่าต้องเล่นแบบไหน — การสลับโหมด

> วัด **25 ก.ย. 2026** จากบันทึกการเล่นจริง 500 รอบ (25 เกม × 20 รอบ)
> ทำซ้ำ: `cd agi3 && PYTHONPATH=. .venv/bin/python scripts/completion_actions.py`

## 1. คำถาม

router เลือกนโยบายจาก `available_actions`: มีปุ่มทิศ → เดิน, มีแต่คลิก → คลิก
แต่ **รายการปุ่มบอกได้แค่ว่ากดอะไรได้ ไม่ได้บอกว่าอะไรผ่านด่าน**
บันทึกจริงตอบได้ เพราะทุกครั้งที่ผ่านด่านมีชื่อ action ที่ทำให้ผ่านติดอยู่

## 2. ผล — 4 จาก 25 เกม รายการปุ่มบอกผิดทาง

| เกม | ปุ่มที่มี | ผ่านด่านด้วย | router แบบเดิมจะทำ |
|---|---|---|---|
| **lf52** | ทิศ + คลิก | **คลิก 15 จาก 15** | เดินตลอดเกม → 0 ด่าน |
| **sb26** | ACTION5 + คลิก | **ACTION5 22 จาก 22** | คลิกตลอด ไม่เคยกด ACTION5 → 0 ด่าน |
| cd82 | ทิศ + 5 + คลิก | ACTION5 5 จาก 5 | เดิน — ตัวใหม่กด ACTION5 เมื่อไปยืนบนวัตถุ |
| sp80 | ทิศ + 5 + คลิก | ACTION5 13 จาก 13 | เดิน — เหมือน cd82 |

**ข้อควรระวัง:** นี่คือบันทึกของ harness เดียว (ผู้ชนะ Milestone #1) บอกได้ว่า action ไหน
*ผ่านด่านได้* ไม่ใช่ว่าอะไร *ดีที่สุด* และเกมลับเป็นคนละชุด —
**ห้ามใช้เป็นกฎรายเกม** ใช้เป็นหลักฐานของกฎทั่วไปเท่านั้น

## 3. กฎทั่วไปที่เพิ่ม

| กฎ | จากหลักฐาน | ราคา |
|---|---|---|
| เกมที่มีทั้งทิศและคลิก: **ไม่ผ่านด่านใน 300 action → สลับไปอีกโหมด** (สลับกลับได้ แต่ละโหมดจำสิ่งที่เรียนไว้) | lf52 | ด่านที่ไม่ผ่านได้ 0 ไม่ว่าใช้กี่ action · ด่านที่ผ่านหลัง 300 action ได้ไม่เกิน (baseline/300)² ของเต็ม — เสียแค่ด่านที่แย่อยู่แล้ว |
| clicker: ถ้ามี ACTION5 ให้ **กด 1 ครั้งทุก 6 คลิกที่ยังไม่ผ่าน** | sb26 (เกมเดียว — หลักฐานบาง จึงทำให้ถูก) | 1 action ใน 7 |

**300 เป็นการตัดสินใจ ไม่ใช่ค่าที่วัดได้** — ต้องทบทวนเมื่อได้เกมจริง
