# วัดช่องว่างเป็นตัวเลข — และสิ่งที่พบคมกว่าค่าสหสัมพันธ์

> วัดเมื่อ 20 ก.ย. 2026 · repo commit `9c5b939`
> ทำซ้ำ: `cd agi3 && PYTHONPATH=. .venv/bin/python scripts/gap_correlation.py --games 12`

## 1. คำถาม

ที่ผ่านมาเรารายงานช่องว่างเป็น "ผ่าน/ไม่ผ่าน" ซึ่งอ้างอิงต่อยาก
คำถามที่ตอบได้ด้วยตัวเลข: **ถ้าเราปรับจูน method โดยดูคะแนนบน simulation
ผลจริงจะดีขึ้นตามไหม**

วิธี: กวาด config ของ `ControlLearner` 18 แบบ (estimator × min_observations × sprite_share)
แล้ววัดสองสนามด้วย config เดียวกัน — **คะแนนบน noise-calibrated mock** (ด่านที่ policy ผ่านได้)
กับ **ความแม่นบน board จริง** (mapping ตรงกับ label) แล้วหาค่าสหสัมพันธ์อันดับ

**ค่าสหสัมพันธ์อันดับ (Spearman): ρ = −0.93** · 18 config · 12 เกม

## 3. ⚠️ ทำไมห้ามอ้าง ρ = −0.93 แบบตรง ๆ

**คอลัมน์ mock มีเพียง 2 ค่าที่แตกต่างกัน: 0 กับ 3** และถูกกำหนดด้วย estimator ล้วน ๆ

| | ผลต่อคะแนน mock | ผลต่อความแม่นจริง |
|---|---|---|
| เปลี่ยน estimator | **0 ↔ 3 (เปลี่ยนทุกอย่าง)** | 59% ↔ 83–86% |
| เปลี่ยน min_observations | **ไม่เปลี่ยนเลย** | ไม่เปลี่ยนเลย |
| เปลี่ยน max_sprite_share | **ไม่เปลี่ยนเลย** | เปลี่ยน ≤3 จุด |

ดังนั้นนี่คือ **การเทียบสองกลุ่ม ไม่ใช่ 18 การสังเกตอิสระ**
การอ้าง ρ = −0.93 ราวกับมี 18 จุดข้อมูลจะ**เกินความจริง**

## 4. ✅ ข้อสรุปที่ถูกต้อง — และคมกว่าเดิม

> **บนพื้นที่พารามิเตอร์ที่กวาด mock ที่ calibrate แล้วแยกแยะได้เพียงแกนเดียว
> คือการเลือก estimator — และมันจัดอันดับแกนนั้น _กลับด้าน_ กับข้อมูลจริง
> ส่วนแกนที่เหลือมันแยกแยะไม่ได้เลย**

พูดอีกอย่าง: simulator ของเราไม่ได้แค่ "ผิดบ้างถูกบ้าง" แต่

1. **ไม่ให้ข้อมูลเลย** บน 2 จาก 3 แกนที่ปรับได้
2. **กลับด้าน** บนแกนเดียวที่มันมองเห็น

และคะแนน mock ออกมาเป็น **0 หรือ 3 เท่านั้น ไม่มีค่ากลาง** — มันทำตัวเป็น
**ประตูผ่าน/ไม่ผ่าน ไม่ใช่สัญญาณที่ไล่ระดับได้** ซึ่งแปลว่าใช้มันปรับจูนอะไรไม่ได้เลยตั้งแต่ต้น

## 5. ผลต่อการใช้งานจริง

ถ้าเราเชื่อ mock แล้วเลือก `overlap` (ซึ่งชนะขาด 3/3 เทียบ 0/3)
เราจะได้ความแม่นบนของจริง **59% แทนที่จะเป็น 86%** — **แย่ลง 27 จุด**

นี่คือต้นทุนที่วัดได้ของการปรับจูนโดยดู simulation

## 6. ข้อจำกัด

- กวาดเพียง 3 แกน · 18 config · 12 เกม
- ทั้งสองสนามวัด**คนละสิ่ง** (ด่านที่ผ่าน vs ความแม่นของ mapping) —
  เทียบกันได้ในเชิงอันดับ แต่ไม่ใช่หน่วยเดียวกัน
- ยังไม่ได้กวาด `MOVEMENT_EPSILON` ซึ่งเป็นค่าคงที่ระดับโมดูล
- **ยังไม่เคยเทียบกับเกมสด** ซึ่งเป็นสนามที่สามที่ยังไม่มีข้อมูล
