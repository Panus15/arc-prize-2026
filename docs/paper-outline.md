## 2. มุมที่แข็งที่สุด

**"โปรแกรมล้วนเรียนรู้อะไรเกี่ยวกับสภาพแวดล้อมที่ไม่เคยเห็นได้บ้าง — และเรียนรู้ไม่ได้อะไร"**

เหตุผลที่มุมนี้เหมาะกับสถานะจริงของเรา:

1. **5 ใน 6 เกณฑ์ให้คะแนนไม่ขึ้นกับ leaderboard** และ bonus เป็น threshold ไม่ใช่อันดับ
2. **เรามีผลลบที่วัดได้จริงพร้อมการแก้** — วิธีแรกได้ 88% บน mock แต่ **0.4%** บนเกมจริง
   แล้วเปลี่ยนวิธีจนได้ **79%** ผลลบที่มีหลักฐานและมีทางแก้มีค่าในงานวิจัยมากกว่าคะแนนที่ขยับนิดหน่อย
3. **เรามีตัวเลขที่ตอบคำถามเชิงปฏิบัติ** ว่าต้องจ่ายกี่ action ถึงเรียนรู้กติกาได้ (40–80)
   ซึ่งเป็นคำถามที่กติกาการให้คะแนนบังคับให้ตอบ
4. ผู้ชนะ Milestone #1 เองได้ completion เฉลี่ย **7.86%** และ **0% ใน 2 จาก 25 เกม** —
   เพดานต่ำมาก การแข่งด้วยคะแนนอย่างเดียวจึงไม่ใช่ทางที่ได้เปรียบ

> ⚠️ แต่ข้อนี้ยัง **ขึ้นกับการมี submission ที่รันได้จริง** ซึ่งยังไม่มี (ดู §5)

### ⚠️ มีหลักฐานบางส่วน

| ข้ออ้าง | ปัญหา |
|---|---|
| "confidence ใช้ตัดสินใจได้" | วัดจาก trace ของผู้ชนะ ไม่ใช่จาก agent เราที่ probe เอง — **ลำดับ probe ต่างกัน** |
| "ClickAgent ใช้ได้กับเกม click จริง" | ทดสอบบน mock ที่เราเขียนเองเท่านั้น **ไม่เคยตรวจกับ trace ของ 8 เกมนั้น** |
| "40–80 action คืองบ probe ที่เหมาะสม" | มาจาก trace ของผู้ชนะซึ่งไม่ได้ตั้งใจสำรวจ ของเราอาจเร็วกว่ามาก |

### ❌ ยังไม่มีหลักฐาน — ห้ามเขียนลงเปเปอร์

| ข้ออ้าง | สถานะ |
|---|---|
| "วิธีนี้ทำคะแนนได้ X บน ARC-AGI-3" | **unsupported** — ไม่เคยรันกับเกมสดเลยแม้แต่ครั้งเดียว |
| "policy เราดีกว่า/แย่กว่าผู้ชนะ" | **unsupported** — ไม่มีคะแนนบน scorecard เดียวกัน |

| "อ่านเลเยอร์สุดท้ายของ frame ถูกต้อง" | **partial** — อ่านจาก engine ในเครื่อง ยังไม่ยืนยันกับ server |

## 5. ช่องว่างที่ต้องปิด เรียงตามความสำคัญ

| # | ช่องว่าง | ผลถ้าไม่ปิด |
|---|---|---|
| **1** | **ไม่เคยเชื่อมกับเกมสด** | ไม่มี submission = **ส่ง paper ไม่ได้เลย** และทุกข้ออ้างเรื่องคะแนนเป็นโมฆะ |
| 2 | ClickAgent ไม่เคยตรวจกับ trace จริง | §5 ของเปเปอร์อ่อน ทั้งที่เป็นส่วนที่น่าสนใจที่สุด |
| 3 | ไม่มีคะแนนจาก scorecard | เขียนเรื่องผลลัพธ์ไม่ได้ ต้องเขียนเรื่องวิธีการล้วน |
| 4 | ไม่ได้ทดสอบลำดับ probe ของเราเอง | ตัวเลข 40–80 เป็นของผู้ชนะ ไม่ใช่ของเรา |

**ปิดช่องว่างที่ 2 ได้ทันทีโดยไม่ต้องใช้เน็ต** — เอา `ClickAgent` ไปทดสอบกับ trace ของ 8 เกมนั้น
ด้วยวิธีเดียวกับที่ทำกับ `ControlLearner`
